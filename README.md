# The SPOOKY ARCADE

An spooky-themed arcade where you play mini-games to earn candies, and enjoy your time. The candies have no practical use yet.

## Features

- Has an authentication system so only users with account pin can access their account.
- 5 unique mini-games.

## Technologies Used

- Python
- Flask
- SQLite
- HTML/CSS

## Why I built this
I built this because I wanted to create a fun app that combined multiple games into one unified experience with theme of halloween.

## How to run (The .exe Version)
1. Download the `.zip` file through demo link and extract it.
2. Open the extracted folder. **Do not move the `.exe` out of this folder** (it needs the `_internal` folder to run).
3. Double-click `arcade.exe`. A black console window will open.
4. Browser will automatically open.
5. **For Reviewers:** You can log in with the developer account to test the shop with high amount of coins.
   - **Username:** `developer`
   - **Pin:** `1111`
